# Unicorn Screener
> Score any startup on its unicorn potential. Get a detailed analysis across five dimensions with a 100-point scoring algorithm.

## About
Unicorn Screener is a startup analysis platform at unicornscreener.vc. Enter any startup name or URL and receive a comprehensive report scoring the startup across five key dimensions: Founder Background, Strategic Position, Execution Velocity, Traction Momentum, and Market & Scalability. Each startup receives a score out of 100 based on a proprietary algorithm backed by academic research on unicorn startups.

## Key Facts
- Website: https://unicornscreener.vc
- Pricing: One free report per user, then $9 per report (one-time, no subscription)
- Agent API: HTTP JSON API with no API key: /api/agent/lookup, /api/autocomplete, /api/request-report, /api/screen-status. Import /openapi.json
- Data sources: Publicly available startup data (Crunchbase, LinkedIn, company websites, news)
- Output: Web memo at /leaderboard/<slug> with scores, evidence, and founder profiles. The request-report API requires an email and sends a memo link when ready
- No account required for the first free report

## Scoring Dimensions
1. Founder Background: Track record, serial entrepreneurship, education, domain expertise, team composition
2. Strategic Position: Market timing, competitive edge, roadmap clarity, vision communication
3. Execution Velocity: Activity cadence, hiring velocity, shipping pace
4. Traction Momentum: Revenue growth, user reviews, investor quality
5. Market & Scalability: TAM, competitive landscape, innovation, defensibility

## Agent workflow
Start with GET /api/agent/lookup?name=<exact startup name> to retrieve an existing score and summary for free (60 requests/hour/IP). found:false does not establish that a company is absent or low quality. Check analyzedAt for freshness.
Resolve ambiguous identities with GET /api/autocomplete?q=<name> (2-60 characters). Empty suggestions do not prove that a company does not exist.
Within the user's authorization, POST /api/request-report with startupName, a permitted non-disposable email, a stable persisted fingerprint, and newsletter:false. This starts a new screening and consumes the free allowance; do not rotate caller identities to bypass quotas.
Success may include memoUrl and slug. Poll GET /api/screen-status?slug=<returned slug> every 10 seconds with a bounded timeout. Follow moved/publishedSlug; stop on ready, failed, refresh-failed or unknown. Do not repeat POST while waiting. If no slug is returned, wait for the email link.
For HTTP 429 limit_reached (email, fingerprint, cookie or ip), stop and use the website for paid options. For rate_limited, respect resetInSeconds when present and otherwise back off. Additional daily IP and hourly limits apply. No unlimited free analysis or private-data access is offered.
